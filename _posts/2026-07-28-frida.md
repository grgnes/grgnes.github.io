# FRİDA

Dynamic binary instrumentation yani çalışma zamanı analizi yapmak için **frida** kullanılır.

Frida, uygulamalara dışarıdan müdahale etmek, çalışma anında bellek değişiklikleri yapmak, güvenlik analizleri yürütmek ve tersine mühendislik çalışmaları gerçekleştirmek için oldukça güçlü bir araçtır.

Açık kaynak kodlu, birden fazla platformda çalışan, programlanabilir çalışma zamanı aracıdır.

Hedefteki uygulamaya çalışma zamanıda JavaScript kodu ekler.

## **Frida'nın Ana Bileşenleri (Türleri)**

| **Bileşen** | **Tanım** | **Kullanım Alanı** |
| --- | --- | --- |
| **Frida Server** | Rootlu cihazlarda çalışan bir sunucu. | Root erişimi olan cihazlarda Frida kullanımı için. |
| **Frida Gadget** | Uygulamanın içine entegre edilebilen Frida versiyonu. | Root erişimi olmayan cihazlarda kullanılır. |
| **Frida CLI** | Terminal üzerinden Frida komutlarını çalıştırmanı sağlar. | Komut satırında Frida kullanımı. |
| **Frida Python API** | Python ile Frida scriptleri yazmanı sağlar. | Otomasyon ve özel testler için. |
| **Frida Trace** | Çalışan uygulamalarda belirli fonksiyonları otomatik izler. | Dinamik analiz, fonksiyon takibi ve API çağrılarının izlenmesi. |


**Frida Server** 

→ Android cihazımıza yüklediğimiz `frida-server` dosyasıdır.

**Frida Client** 

→ Bilgisayarında çalışan ve Frida Server’a bağlanmayı sağlayan araçtır.

**Frida Trace** 

→ Çalışan uygulamalarda belirli fonksiyonları otomatik izler.

→ Dinamik analiz, fonksiyon takibi ve API çağrılarının izlenmesini sağlar.


### **Frida Temel Çalışma Modları**

**Injected** 

Android uygulamada fridanın ajanı uygulamanın bellek alanına yazılır ve bu ajanla komut satırı üzerinden haberleşilir. Bu modun kısıtı hedefimizde ki cihaz Android ise rootlu olması, IOS ise jailbreak olması gerekir.

**Embedded (Gömülü) →** Frida Gadget

Hedefimizdeki cihaz rootlu veya jailbreak değilse kullanılır. Elimizde ki uygulamayı decompile edip içerisine frida gadget denilen frida ajanını ekleyip uygulamayı tekrar paketlenir. Uygulama cihaza kurulduğunda içinde frida gadget ile kurulmuş olur ve injected modta olduğu gibi frida ile haberleşilir.

**Preloaded (Önyüklü)** 

Aynı embedded modtaki gibi çalışır. Gömülüden farklı olarak frida gadget’ın içerisine önceden eklenmiş script kodunu bizden girdi almadan kendi başına tetikleyebiliyor olmasıdır.

### **Frida ile Neler Yapılabilir?**

- Diğer uygulamalar ile haberleşebilir.
- Yerel diske erişim sağlayabilir.
- Metotların parametrelerini dönüş değerlerini inceleyebilir.
- Metot gerçeklemelerini değiştirebilir.
- Yeni metotlar yazıp bu metotları çağırabilir.
- Mevcut uygulamanın yetkilerini kullanır.

### **Kurulumu**

Frida’nın cihaza kurulumu :

Cihazda python olmalısı önemlidir. Güncel sürümüne göre indirin.

```bash
pip3 install frida
```

```bash
pip3 install frida-tools
```

Android cihaz için kurulum :

1)  frida.re sayfasına gidilir, tutorials ‘tan android kısmındaki maddeleri takibe başlanır.
2) Frida-server kurulumu için https://github.com/frida/frida/releases dan cihaza uygun sürüm indirilir.
    
<img src="/assets/posts/frida/fridadownload.png" width="500" >
    
3) Cihaza uygun sürüm bulma :

```bash
> adb shell getprop ro.product.cpu.abi
x86
```

4) Uygun olan sürüm dosyası indirildikten sonra indirilen sıkıştırılmış dosya halinden kurtarılır ve adı düzenlenilir.

```bash
> & "C:\Program Files\7-Zips|7z.exe" x frida-server-16.6.6-android-x86.xz
```

```bash
> mv .\frida-server-16.6.6-android-x86 frida-server
```

5) İndirilen dosya mobil cihaza gönderilir.

```bash
> adb push frida-server /data/local/tmp
```

6) Frida-server dosyasını çalıştırılabilir hale getirilir

```bash
> adb shell chmod +x /data/local/tmp/frida-server
```

7) Sunucu başlatılır

```bash
> adb shell
```

### Frida'nın farklı kullanım ve analiz yöntemleri

### **1. ptrace()**

- **ptrace()**, **Linux sistem çağrısıdır** ve bir sürecin başka bir süreci izlemesine veya kontrol etmesine izin verir.
- **Frida'da doğrudan bir modül olarak bulunmaz** ama anti-debug korumalarını atlatmak için kullanılır.
- **Uygulamalar bazen ptrace() kullanarak kendilerini analiz edilmekten korurlar** (örneğin `ptrace(PTRACE_TRACEME, 0, 0, 0)` ile).
- Frida ile çalışırken **anti-debug mekanizmalarını atlatmak için ptrace patching (yama) yapabiliriz.**

### **2. Frida Gadget**

- **Root/Jailbreak gerekmeyen Frida kullanım şeklidir.**
- Uygulamayı **decompile edip içerisine gadget ekleyerek** Frida'yı içine gömeriz.
- **Özellikle kapalı sistemlerde (root'suz telefonlar gibi) kullanılır.**
- **İki modda çalışabilir:**
    - **Injected Mode**: Komut satırından yönetilir.
    - **Preloaded Mode**: Önceden belirlenen bir script çalıştırır.

### **3. Frida Trace**

- **Frida'nın API çağrılarını dinlemek için kullandığı bir araçtır.**
- Örneğin, bir Android uygulamasında `open()`, `read()`, `write()`, `send()`, `recv()` gibi fonksiyonları izlemek için kullanılır.
- Şu şekilde başlatılır:
    
    ```powershell
    frida -U -n com.example.app -i open
    ```
    
    Bu komut, **`open()` sistem çağrısını izler ve hangi dosyaların açıldığını gösterir.**
    
- **Dinamik analiz yapmak için güçlü bir araçtır**

### **4. jnitrace()**

- **JNI (Java Native Interface) çağrılarını izlemek için kullanılır.**
- Android uygulamalarında **C/C++ koduna yapılan çağrıları görmek için idealdir.**
- Şu komutla başlatılır:
    
    ```powershell
    frida -U -n com.example.app -e "Java.perform(function() { jnitrace('*'); });"
    ```
    
- **Özellikle şifreleme algoritmalarını ve güvenlik kontrollerini analiz etmek için kullanılır.**
