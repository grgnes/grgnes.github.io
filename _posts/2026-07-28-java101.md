## Class

- Şablon, kalıp
- Bir şeyin nasıl yapılacağını, hangi değişkenlere(özelliklere) ve metotlara(davranışlara) sahip olduğunu tanımlar.

```java
public class Araba {
    String renk;
    int hiz;

    void calistir() {
        System.out.println("Araba çalışıyor");
    }
}
```

## Object

- Class’tan oluşturulmuş bir gerçek örnektir.

```java
Araba benimArabam(object) = new Araba();
benimArabam.renk = "Kırmızı";
benimArabam.hiz = 100;
benimArabam.calistir();
```

## Method

Class içerisinde tanımlanan fonksiyondur.

```java
public class Araba {

    void calistir() {
        System.out.println("Araba çalışıyor");
    }

    void hizlan() {
        System.out.println("Araba hızlanıyor");
    }
}
```

```java
Araba benimArabam = new Araba();
benimArabam.calistir();  // “Araba çalışıyor” yazdırır
benimArabam.hizlan();    // “Araba hızlanıyor” yazdırır
```

Javada cast yapma mantığı, bir objectin türünü belirlenmemişse ona tür atamak için kullanılır. Peki neden türünü belirlemeyiz, daha esnek kullanmak için yani ben onu int olarakta belirlemek isteyebilirim, string olarakta belirleyebilirim.

```java
List<Object> liste = new ArrayList<>();
liste.add("merhaba");
liste.add(123);
liste.add(new MyClass());
```

## METHOD ÇEŞİTLERİ

1. Public Method

Her yerden erişilebilir.

```java
public class Ornek {
    public void genelMetot() { }   // her yerden erişilebilir
}
```

2. Private Method

Sadece tanımlandığı sınıf içinden erişilebilir.

```java
public class Ornek {
    private void gizliMetot() { }  // sadece bu sınıf içinden
}
```

3. Protected Method

Aynı paket veya alt sınıflardan erişilebilir.

```java
public class SuperSinif {
    protected void korumaliMetot() {
        System.out.println("Ben protected metodum.");
    }
}
public class AltSinif extends SuperSinif {
    public void test() {
        korumaliMetot();  // Aynı paket içinden erişim mümkün
    }
}
```

4. Static Method

Class’ a aittir, nesne oluşturulmadan çağrılabilir.

```java
public class Ornek {
    public static void selamla() {
        System.out.println("Merhaba!");
    }

    public static void main(String[] args) {
        Ornek.selamla();  // Nesne oluşturmadan çağrıldı
    }
}
```

5. Instance Mehod

Nesne oluşturularak çağrılan metotlardır. Statik kullanılmaz.

```java
public class Ornek {
    public void yaz() {
        System.out.println("Ben nesneye ait bir metodum.");
    }

    public static void main(String[] args) {
        Ornek o = new Ornek(); // nesne oluşturuldu
        o.yaz();  // nesne üzerinden çağrıldı
    }
}
```

6. Abstract Method

Sadece bildirimi yapılır, gövdesi yazılmaz. Classlarda kullanılır.

```java
abstract class Hayvan {
    public abstract void sesCikar();
}

class Kedi extends Hayvan {
    @Override
    public void sesCikar() {
        System.out.println("Miyav");
    }
}
public class Main {
    public static void main(String[] args) {
        Hayvan kedi = new Kedi();
        kedi.sesCikar();   // Miyav
    }
}
```

7. Final Method

Alt class’larda override edilemez/değiştirilemez. 

```java
public class Hayvan {
    public final void hareketEt() {
        System.out.println("Hareket ediyorum");
    }
}

```

8. Constructor Method

Sınıf ismi ile aynı olur, geri dönüş tipi yoktur, nesne ilk oluşturulduğunda çağrılır. 

Sınıftan nesne oluşturulurken, başlangıç ayarlarını yapmak için kullanılır. → ilk önce nesne oluştu yazacak terminalde

```java
public class Ornek {
    public Ornek() {
        System.out.println("Nesne oluştu");
    }
}
```

```java
public class Main {
    public static void main(String[] args) {
        Ornek o = new Ornek();  // ← Constructor otomatik çalışır
    }
}
```

9. Overloaded Method

Aynı isimde, farklı parametrelerle birden fazla metot tanımıdır.

```java
public void yaz(String s) { }

public void yaz(int s) { }  // farklı parametre = overload
```

10. Override Edilmiş Method

Kalıtımda (inheritance) alt sınıf, üst sınıftaki metodu yeniden tanımlar.

```java
class Hayvan {
    public void ses() {
        System.out.println("Ses çıkar");
    }
}

class Kedi extends Hayvan {
    @Override
    public void ses() {
        System.out.println("Miyav");
    }
}

```

extends → class başka bir classtan miras alıyorsa

override → üst sınıftaki bir metodu alt sınıfta yeniden yazmak (hooklamak)
